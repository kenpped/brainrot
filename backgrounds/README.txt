Drop your gameplay loops here as .mp4 / .mov / .mkv / .webm.

Organize by tag subfolder so scripts can pick their footage:

  backgrounds/
    minecraft/   <- bg: minecraft front matter, or --bg-tag minecraft
    subway/
    gta/
    roblox/      <- your own games, 100% yours to record
    synthetic/   <- make_bg.py output (copyright-free)

- with no tag, any video anywhere in here can be picked
- 10+ minutes per file is ideal so the random start offset actually varies
- vertical or horizontal both work, the renderer center-crops to 1080x1920
- files shorter than a video get looped automatically
- this folder is gitignored on purpose: big binaries + someone else's footage

Record your own: Win+G (Game Bar) is built into Windows, OBS for longer runs.
Footage downloaded from someone else's channel is theirs, not yours.
