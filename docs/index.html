What it does

Topic to videoType a topic, the AI writes the script through your local Claude Code, the pipeline voices and renders it. One command or one click.
AI characters7 original personas with their own voices, pitch shifts, caption colors, and personalities the AI writes dialogue in. Robot vs demon is a genre.
Voice effectsRobot, demon, chipmunk, megaphone, radio, phone, echo. ffmpeg processing over 400+ free voices. No voice cloning, ever.
Word-pop captionsWhisper word timestamps drive one-word-at-a-time captions with accent colors. Impact 130, outline 9, the loud look.
Local web studioA localhost site with style presets, cast pickers, font preview, background uploads, job queue, and a video gallery.
Batch + resumePoint it at a folder of scripts. Kill it whenever. It skips what's rendered and keeps voices stable per script.

Quick start

git clone https://github.com/kenpped/brainrot
cd brainrot
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
winget install Gyan.FFmpeg

python webapp.py        # the studio, at localhost:8765
python make_bg.py       # copyright-free backgrounds to start with
Why is it free? Because nothing runs on a server. Rendering, voices, and captions all happen on your machine, and script writing uses your own local Claude Code. No accounts, no credits, no watermark, nothing to sell you. Bring your own gameplay footage and be smart about whose footage it is.
